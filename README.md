## AS4837 到底是什么线路，跟 9929、CN2 GIA 有什么区别

简单说清楚原理：AS4837 是中国联通的骨干网编号，前身是网通拆分电信 163 网之后独立出来的 CHINA169 骨干网，2008 年联通网通合并后归入联通。它的特点是负载相对较低、三网直连表现均衡，晚高峰不容易崩，缺点是随着上车的人越来越多，部分线路也开始出现拥堵迹象。

跟另外两条常被拿来对比的线路相比，联通 AS9929（也就是所谓的 CU Premium）走的是联通香港 AS10099 出口，国内段才转 AS9929，理论上比纯 AS4837 更稳，但因为线路成本高出不少，市面上带 AS9929 的产品普遍带宽和流量给得很小，价格也贵不少。CN2 GIA 则是电信自己的高端专线产品，稳定性和延迟通常是三者里最好的，价格自然也最高。用一句话总结的话：AS4837 是三者里性价比最突出的那个，但不是绝对最优解，预算充足或者对稳定性有硬性要求的场景，还是应该优先考虑 CN2 GIA 或 AS9929。

还有一点值得注意：AS4837 线路里，圣何塞机房的回程表现普遍优于洛杉矶机房，这是这条线路本身的一个特性，跟具体商家关系不大。LisaHost 的 AS4837 产品目前是洛杉矶机房，这不代表它不能用，但如果你对回程延迟特别敏感，选购前最好先看看第三方测速数据，而不是只冲着「AS4837」这个标签下单。
